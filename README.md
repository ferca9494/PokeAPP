# PokeAPP

## English

### Description
PokeAPP is a web application that displays data from the PokeAPI. You can explore detailed information about different Pokémon, use filters to refine your search, and enjoy a built-in Pokémon memory game. More features are planned for the future.

### Features
- View detailed information for every Pokémon, including stats, abilities, types, and images.
- Filter Pokémon by criteria such as type, generation, or name.
- Responsive design for desktop and mobile devices.
- Built-in Pokémon Memory Game: Test your memory skills by matching Pokémon pairs.
- (Planned) Additional interactive features and mini-games.

### Technologies Used
- HTML
- CSS
- JavaScript
- [PokeAPI](https://pokeapi.co/)

### Future Improvements
- Complete information for all Pokémon.
- Advanced filtering options.
- Add more Pokémon-themed games.
- Improve user interface and user experience.
- Multi-language support (English & Spanish).

## Español

### Descripción
PokeAPP es una aplicación web que muestra datos de la PokeAPI. Puedes explorar información detallada sobre diferentes Pokémon, utilizar filtros para refinar tu búsqueda y disfrutar de un juego de memoria de pokemones incluido en la app. Se planean más funciones para el futuro.

### Funcionalidades
- Ver información detallada de cada Pokémon, incluyendo estadísticas, habilidades, tipos e imágenes.
- Filtrar Pokémon por criterios como tipo, generación o nombre.
- Diseño responsivo para computadoras y dispositivos móviles.
- Juego de Memoria de Pokemones: Pon a prueba tu memoria emparejando pokemones iguales.
- (Próximamente) Más funciones interactivas y mini-juegos.

### Tecnologías Utilizadas
- HTML
- CSS
- JavaScript
- [PokeAPI](https://pokeapi.co/)

### Mejoras Futuras
- Información completa para todos los Pokémon.
- Opciones de filtrado avanzadas.
- Agregar más juegos temáticos de Pokémon.
- Mejorar la interfaz y experiencia de usuario.
- Soporte multilenguaje (inglés y español).
